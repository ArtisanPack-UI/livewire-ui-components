# Event Modal Content Component

> **Internal in 3.0.** `event-modal-content` is the [Calendar](calendar)'s internal child for an event's details Dialog, not public API. To show your own details, pass `event-view` to the Livewire Calendar: it's mounted with the event (`mount( array $event )`). See [Event details](calendar#event-details).
