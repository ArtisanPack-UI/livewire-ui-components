# MenuItem Component

A link (or a button without `href`) in a [Menu](menu). See [Menu](menu) for its props, examples and accessibility notes.

```blade
<x-artisanpack-menu-item :href="route( 'inbox' )" icon="mail" :badge="$unread">{{ __( 'Inbox' ) }}</x-artisanpack-menu-item>
```
