Instructions for Testing

1. Try pressing Tab to navigate to each dropdown trigger

2. Press Enter to open the dropdown - it opens but focus doesn't move inside

3. Try using arrow keys to navigate within the dropdown - doesn't work

4. Press Escape to close - doesn't work

5. Click outside to close - this works

Expected Accessible Behavior

  • Dropdowns should open/close with Enter and Space keys
  • When opened, focus should move to first menu item
  • Arrow keys should navigate between menu items
  • Escape should close dropdown and return focus to trigger
  • Tab should close dropdown and move to next focusable element
  • ARIA attributes should indicate state and relationships
